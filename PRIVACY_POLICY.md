# Privacy Policy for SearchBoundary

Last updated: March 18, 2026

SearchBoundary is a Chrome extension that helps users analyze search result pages and discover related directions through a keyword cloud sidebar.

## What SearchBoundary processes

SearchBoundary processes content from supported search result pages, including titles, snippets, links, and optionally fetched page text, in order to generate keyword analysis for the user.

The extension also stores user preferences locally, including:

- panel language
- fetch depth
- keyword limits
- selected provider
- endpoint
- model name
- optional API key

## How data is used

SearchBoundary uses processed page content only to provide its core functionality: keyword extraction, visualization, and related result exploration.

In local mode, keyword extraction is performed locally.

In cloud mode, extracted page text and related prompts may be sent to the third-party API endpoint configured by the user for keyword analysis.

## Data sharing

SearchBoundary does not include built-in analytics, advertising, or tracking services.

If the user enables cloud mode, relevant extracted content may be transmitted to the user-selected third-party LLM provider or compatible API endpoint. In that case, data handling is also subject to the privacy practices of that provider.

## Data storage

SearchBoundary stores settings in `chrome.storage.local` on the user's device so the extension can remember configuration across sessions.

## What SearchBoundary does not do

SearchBoundary does not sell user data.

SearchBoundary does not use collected data for advertising purposes.

SearchBoundary does not collect account credentials, payment information, or personal identity documents.

## User control

Users can stop data processing by disabling or uninstalling the extension.

Users can clear locally stored extension settings through Chrome extension storage controls or by removing the extension.
